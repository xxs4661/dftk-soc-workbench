# Workbench validation environment

This environment belongs to the workbench. It does not modify either upstream project.
`Project.toml` and `Manifest.toml` were generated by Julia Pkg with `preserve=Pkg.PRESERVE_ALL`,
using the prior local DFTK Manifest as the initial resolution seed. All 157 shared package
versions were retained. The two source packages are relative path dependencies at the
commits in `../../config/sources.lock`. No source lock was changed.

Use Julia **1.12.7**, as recorded in the Manifest. From the workbench root:

```sh
bash scripts/fetch_sources.sh
bash scripts/bootstrap_dftk.sh
python3 scripts/run_recorded.py tests
PYTHONDONTWRITEBYTECODE=1 python3 tests/test_recorder.py
bash scripts/run_upf_inspection.sh
```

For a local rebuild, `fetch_sources.sh --source-cache /path/to/existing/.work` clones the
source Git repositories into the new workbench's own ignored `.work` directory, then
verifies the locked commits and clean worktrees. The source cache is not a runtime path.
You may set `JULIA_DEPOT_PATH` to an existing download cache; otherwise the runner uses
`.work/julia-depot`. It restricts `JULIA_LOAD_PATH` to `@:@stdlib`.

Fetch the source checkouts **before** instantiation. Bootstrap only instantiates the
saved resolution; it does not develop/add/update packages. A changed fingerprint or
Julia version, dirty source checkout, missing dependency, or compatibility problem is
non-passing. Do not refresh checksums merely to bypass an error. Any deliberate
environment update needs review and Pkg-generated Project/Manifest changes.

`checksums.toml` fingerprints the saved Project, Manifest and source lock. Every fresh
worker records the active project and actual Manifest, Julia version, `pathof` values,
UUIDs, versions, loaded checkout roots, commits and worktree status. Real paths are
compared before public output is redacted. A matching checkout elsewhere cannot satisfy
the loaded-path check.

The Mac MPI implementation may require execution outside a restricted process sandbox.
An initialization failure is a failed environment check, not evidence of validation.

The original PBEsol Mg sample remains a metadata-inspection input only. It is not a
validated LDA/LSDA benchmark, and its redistribution permission remains unverified.
